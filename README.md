# Triyan Agung Laksono — Academic × Technology Portfolio

Personal academic and technology portfolio published with GitHub Pages.

- Animated academic-tech landing page
- About / four professional dimensions
- Selected public, private, and product work
- Research highlights
- Teaching preview
- Academic profile links

Future iterations will expand Projects, Research/Publications, and Teaching into dedicated pages after the V1 homepage has been visually reviewed.
